# Manfaz VPN 2.26.0

This release is about the parts of the app you touch first. Setting it up now guides you
instead of leaving you to find things, the connect button stopped naming the wrong server, the
protective settings can be applied in one action, and the two tabs that each told half the
story about your connection history are now one page.

## Setting up is now guided

A new account had to work out what to do next on its own. The home screen offered a list of
instructions and left you to carry them to another tab.

When no subscription exists yet, the home screen now leads with a card that says what is
needed and takes you straight to the place where you add it. Once something is configured the
card is gone, so it is a starting point rather than a permanent fixture.

## AI Settings

Settings opens with a new section. One action applies the combination that is genuinely worth
having and that almost nobody assembles by hand:

- The internet kill switch
- System DNS on Cloudflare Smart
- Encrypted DNS inside the tunnel
- Advanced TLS, meaning a Chrome fingerprint, ECH, and handshake fragmentation

Every step reports its own result underneath. If a step cannot be applied, and arming the kill
switch on a machine without Administrator rights is the common case, that step is marked as
failed with the reason. This matters more than it sounds: a preset that silently skips the
protection you asked for is worse than no preset, because you would carry on believing you
were covered.

## The connect button named the wrong server

The subtitle under the connect button always showed whichever server was currently fastest,
including while the app was busy dialling a completely different one. If you picked a server
from the list, the button still named another.

It now names the server the action actually concerns: the node being tried during an attempt,
and the one you selected when idle.

## Statistics and Logs are one page

They were two tabs answering different questions about the same history, which meant checking
both to understand a single connection.

They are now a single Activity page. The totals sit on top and stay visible, and a switch
below moves between per-session history and the event log, each showing how many entries it
holds. Nothing was removed, including the technical report you can copy to the clipboard.

## Persian numbers were showing up in English

Numbers and dates were formatted for Persian no matter which language was selected, so the
English interface showed Persian digits and a Persian calendar. The total connection time was
the worst of it: at small sizes the Persian zeros rendered as a row of dots rather than a
readable `00:00:00`.

Formatting now follows the language you have chosen, everywhere.

## Installing

Windows 10 or 11, 64 bit. Both engines are included, so there is nothing to fetch on first
launch.

Run the app as Administrator if you want TUN, the kill switch, or system DNS changes. Without
elevation everything else still works over System Proxy, and AI Settings will tell you plainly
which step it could not complete.

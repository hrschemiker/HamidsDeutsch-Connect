## DNS, without compromise

Manfaz 2.18.0 makes DNS a first-class connection mode on Windows.

### Highlights

- Connect through a validated DNS resolver without starting a VPN session.
- Keep custom DNS profiles locally, with user profiles prioritized ahead of built-in services.
- Use Cloudflare automatically when no custom profile has been saved.
- Apply custom DNS alongside an active VPN connection.
- Restore the exact per-adapter Windows DNS baseline on DNS disconnect, VPN disconnect, or application shutdown.
- Validate resolver reachability before changing system configuration.
- Use a consistent control and typography scale throughout application settings.

### Under the hood

DNS changes now follow the same transactional lifecycle as connection changes: capture, validate, apply, verify, and restore. Shutdown cleanup also covers tray-initiated exits, preventing session-scoped DNS configuration from remaining active after Manfaz closes.

The repository documentation has been rebuilt around routing, recovery, DNS lifecycle, update behavior, and verifiable connectivity.

# Manfaz VPN 2.23.0 — Smart DNS & Reliability

This release turns DNS, recovery, and multi-engine behavior into one safer lifecycle while refining the interface around the way the app actually works.

## Smart DNS

- Added **Cloudflare Smart** as the default DNS profile. Manfaz tests the best Cloudflare edge discovered at launch with a real encrypted DoH query before using it.
- A scanned edge is never trusted just because port 443 is open. If encrypted DNS validation or the post-apply Windows lookup fails, Manfaz rolls back and uses `1.1.1.1` automatically.
- Kept **Cloudflare Traditional** as a separate `1.1.1.1 / 1.0.0.1` profile.
- Added a persistent multi-profile DNS library with validation, duplicate prevention, custom names, up to 50 profiles, and migration from the previous local UI storage.
- Custom DNS profiles now participate in settings export/import and remain available for both DNS-only sessions and VPN DNS selection.
- Smart Cloudflare DNS uses HTTPS through sing-box. Xray deliberately keeps the traditional Cloudflare resolver until equivalent pinned-DoH routing is available.

## Connection and recovery

- Extended upstream SOCKS5/HTTP chaining to Xray and sing-box TUN configurations.
- Restricted Cloudflare clean-IP substitution to endpoints that resolve entirely to Cloudflare infrastructure; unrelated servers are never rewritten.
- Expanded one-click network repair to stop both engines and restore DNS in addition to clearing the Windows proxy, engine ports, and Kill Switch rule.
- Free configurations now require two consecutive real-relay failures before removal, avoiding destructive pruning after a temporary network timeout.
- Corrected live throughput calculation so the UI no longer differentiates an already calculated bytes-per-second value a second time.
- Preserved strict egress verification: a listening local core is never reported as a connected VPN without a proven route change.

## Privacy and safety

- Added explicit consent before sending a subscription URL to a public conversion service and display the converted content instead of exposing a conversion URL containing the original subscription.
- Updated the dependency graph to patched releases; the production audit reports zero known vulnerabilities.
- DNS changes are tested before and after application and are rolled back transactionally on failure.

## Interface polish

- The connection-engine selector now correctly identifies sing-box as the default and Xray as the optional alternative.
- Restored visible scroll affordance, fixed reconnect and free-pool progress feedback, and made the connected hero control keyboard accessible.
- Removed obsolete UI styles and inactive feature remnants, reducing the stylesheet substantially without removing working functionality.
- Fixed stale onboarding text, version labels, update-state colors, dialog semantics, and language metadata.

## Update delivery

The Windows installer, block map, and update manifest are published with this release so permission-first automatic updates can complete end to end.

# Manfaz VPN 2.24.0 — A Smaller, Safer Client

This release removes the public free-configuration feature entirely and spends the
saved surface on the two things that protect a connection: the Kill Switch and
TUN mode. The interface also gets a pass for the parts that only ever worked in
Persian.

## Free configurations removed

- Removed the Telegram crawler, the shared free-config pool, and the offline
  GeoIP lookup that fed it, along with every background task, control channel,
  and setting that existed only for that feature.
- Dropped the bundled 3.2 MB country database that was read only by that lookup.
- Connecting now goes through your own subscriptions. When no subscription has
  been added yet, the home screen says so instead of failing quietly.

## Kill Switch

- Fires on any unplanned engine exit. It previously required a non-zero exit
  code, so a clean but unrequested exit left the machine unprotected.
- Confirms the Windows Firewall rule was actually created rather than trusting
  the command's exit status, and reports a failed activation instead of only
  writing it to the log.
- Keeps the blocked-internet dialog open when releasing the block fails. It used
  to close and report success while the network was still cut off.
- No longer treats the next genuine drop as intentional after a disconnect that
  had nothing running to stop.
- Stays armed across a bypass-list reload, which restarts the engine underneath
  an unchanged connection.
- Requires Administrator up front: the switch is shown as unavailable with an
  explanation instead of failing at the moment it is needed.

## TUN mode

- Waits for the exit address to change instead of checking once. Windows installs
  TUN routes asynchronously, so the single immediate check read the pre-tunnel
  route and tore down tunnels that were about to work.
- Clears the tunnel state when the engine stops, so a finished session no longer
  reports itself as connected.
- Derives the DNS-over-HTTPS server name and path from the resolver you selected.
  A hardcoded Cloudflare name broke the handshake for every other resolver, so
  nothing resolved inside the tunnel.
- Reports the underlying reason a tunnel failed instead of one generic message.
- Fixed an unterminated handler registration in the main process that attached
  the TUN configuration check as an argument to the preceding handler.

## Interface

- English no longer renders Latin digits as Persian numerals; addresses, versions,
  and latencies read correctly in both languages.
- The document root now follows the selected language and theme, which fixes the
  page background, the scrollbar side, and how native controls are drawn.
- Navigation items and server rows use logical alignment instead of a fixed
  right-hand edge that mis-aligned the English layout.
- The leading navigation tabs stay reachable once the bar overflows.
- Scrollbars follow the active theme instead of staying dark on a light page.
- Narrow windows scroll to the bottom instead of clipping the page.
- The service card no longer forces right-to-left onto English copy.
- The header shows the running application's version rather than a value kept in
  step by hand.
- Switching the connection engine asks through the application's own dialog
  instead of a native system prompt that froze the window.
- Error notifications no longer arrive wearing a success mark.
- The remaining Persian-only strings — connection stages, errors, the update
  banner, and accessibility labels — are translated.

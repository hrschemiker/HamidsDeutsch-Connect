## Clean disconnects, calmer navigation

Manfaz 2.20.0 tightens the Windows network cleanup path and refines the home experience.

### Reliable Windows Proxy recovery

- Every explicit disconnect now runs Proxy restoration even when the renderer or engine status is stale.
- A legacy backup that accidentally contains Manfaz's own `127.0.0.1:2080` endpoint can no longer restore a dead local Proxy.
- Genuine user-configured Proxy settings remain protected and are restored from the captured baseline.
- DNS-only disconnects also act as a safe recovery boundary for an interrupted Manfaz VPN session.

### Home and settings refinements

- The Manfaz service promotion now uses left-aligned copy and links directly to `@ManfazVpnBot`.
- The sticky Settings section navigator has been removed.
- The public-configuration notice now sits over a translucent glass layer, leaving the protected list visibly recognizable underneath.
- Acknowledging the public-configuration warning lasts for the entire application session and no longer resets when navigating between tabs.

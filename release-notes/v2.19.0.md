## DNS follows the connection

Manfaz 2.19.0 completes the DNS lifecycle introduced in the previous release.

### What changed

- The DNS profile selected in Settings is now compiled directly into sing-box for both TUN and System Proxy connections.
- Resolver traffic follows the VPN route instead of creating a separate standalone DNS session.
- The DNS-only connection remains available while disconnected, then becomes inactive and visually subdued for the duration of a VPN session.
- Starting a VPN safely restores any active standalone Windows DNS state before the tunnel is created.
- Direct-route DNS rules continue to use the local resolver path, preserving split-routing behavior.

### Safer public configurations

Public free configurations are now protected by a startup-scoped safety notice. Their contents stay obscured until the user acknowledges that these servers are intended for emergency use and carry no security or privacy guarantee.

### In this release

- A new Manfaz service promotion completes the home connection layout.
- The artwork and its surrounding treatment are tuned for both light and dark themes.
- The Windows installer is attached to this GitHub release.
